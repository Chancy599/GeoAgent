### 首轮后的定向复核

150 张首轮生成后，以下样本由 Code Agent 按原图修订，再经 Critic 和拓扑检查。两组最终消融都使用同一份修订后的代码。

- `1262_s_fig1` 使用 E 作为 AB 上的共享端点。
- `1266_s_fig1` 补齐实线 E–C，与 F–O–E 连成一条路径。
- `1311_s_fig1` 补齐圆内的 C–E 虚线弦。
- `1316_s_fig1` 在 AC 的路径中使用交点 D 和垂足 F。
- `1251_s_fig1` 移除 Q–O–P 和 A–P–B 上重复描画的两个伪延长段，给 O 标签留出笔画间距。
- `1479_q_fig4` C 重新绑定到实线 AD 与 G–C–F–B 的交点，竖向虚线 C–E 从同一交点起笔。

首轮全自动输出的配对误差也已计算。角度 MAE 从 2.0565° 降至 1.0500°，长度比 MRE 从 1.7012% 降至 1.0349%。首轮完整配对汇总和定向修订版本见 [生成清单](input_manifest.json)。
