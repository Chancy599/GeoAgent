## 1251_s_fig1 与 1479_q_fig4 定向复核

- `1251_s_fig1` 的两个检测端点落在既有的 Q–O–P 和 A–P–B 内部。程序现在会排除被具名实线覆盖的候选延长线。
- `1479_q_fig4` 原先将 C 绑到虚线检测端点 (235.50, 171.55)。Geometry Agent 复核后选用交点候选 (247.09, 187.45)，Code Agent 在实线 AD、虚线 GC、实线 CF 和虚线 CE 中使用同一 C 点。
- `1479_q_fig4` 的参考 TikZ 注释将 C 描述为 AD 上的点，字面坐标却偏离 AD。按现有评测，修订版的 A–C 和 C–D 各计为一个额外具名线段。对照原图，二者共同组成已有的 AD 实线。
