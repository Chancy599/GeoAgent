# GeoAgent 投稿研究路线：免训练方法，4–6周

更新日期：2026-11-01。已有事实以[当前100图报告](../results/latest/report.md)和[描述审计](../results/latest/research_audit.json)为准。下面的新方法、独立测试及新增数据仍为研究计划，不能作为已完成贡献。

## 1. 主线：什么时候修复、应该回到哪一层修复

拟题：GeoConstruct: Evidence-Grounded Selective Repair for Geometric Image-to-Code Reconstruction。

建议以原图证据和测量可靠程度驱动的选择性生成后修复为主要方法，再加一次有预算限制的局部重新测量。多智能体编排、工具集合、编译回退和轨迹保存提供实现基础，不能分别充当主要创新。

## 2. 已完成的评测整理

当前只评测有可见标签的点，按“可见标签 → 代码绑定坐标”对应，不匹配无标签点，不运行空间点匹配。100张参考图的角度和线段比例已独立保存到`data/test/geometry_reference`；评测只读JSON与output程序，缺标签、冲突、缺边和退化边均报告覆盖率。协议详见[流程文档](pipeline.md)。

`6986`中可见E的实际绑定与同名内部坐标E不同。当前记录原始绑定冲突，并经审核把参考E修正为BC与上半圆的第二交点；修正构造与源文件哈希保存在corrections.json。原始TeX未改变，这也说明参考源码本身仍需要人工语义审计。字面文字位置若被用于排版，不能仅凭就近关系断言其真实顶点。

结果表不在本文复制，统一引用当前报告，避免多份数字不同步。当前100图已经用于开发；视觉指标不能替代几何误差与覆盖率，DINO轻微下降也应如实报告。两个e2e已用相同标签协议重测，见[baseline几何结果](../results/latest/baselines_geometry.json)；当前只保留同批TikZ的不修复消融，旧版消融已移除。参考质量审计发现并修正了6983圆心及圆周点偏移；50标签遗漏、1615端点和6987折线问题已按源图证据优化。1630和411按实际代码评测。

## 3. 下一步优先验证

1. 人工审核参考标签与绑定，尤其是同名坐标冲突、字面文本偏移和参考近似构造；评测清单必须在观察方法结果之前冻结。
2. 对真实接近90°但非直角、近但不平行、短边遮挡等负例做控制扰动，验证不会错误精确化。
3. 引入来自原图线拟合/重采样的测量稳定性，比较固定阈值、固定权重、测量加权及选择性接受。
4. 对大点位错误和漏边，比较一次局部重测与等预算直接修改；不能期待小位移后修复解决结构遗漏。
5. 将当前100图当开发集，预留未使用题目和不同生成器输出，最终冻结后只做一次主测试。

## 5. 可做的 idea，按本次目标排序

### A. 原图证据驱动的选择性后修复：优先级最高

**问题。** 当前 `numeric_candidates` 只读取生成坐标；近 90° 或近平行就成为候选。求解器又以原始生成坐标为锚。它既不能知道接近是否只是巧合，也很难纠正生成阶段已经发生的大点位误差。

**方案。** 保持生成后处理位置，但给后处理接入原图的可追溯测量：

- 建立生成点/线与图像测量的对应，并单独估计像素到 TikZ 的相似变换。禁止用参考代码做这一步。
- 对线条支持像素做鲁棒拟合和重采样，得到方向、交点的稳定性或协方差。长直边与短边、清晰点与遮挡交点不应拥有相同移动代价。
- 不确定性必须来自测量扰动和已知真值验证，不能直接让 LLM 编造 confidence；无对应或无稳定测量时保留原结果。
- 只有数值候选且有图像支持时才考虑精确化。显式直角标记与纯角度接近分开处理；文本条件只在单独的 image+text 任务中使用。
- 先实现加权连续求解与拒绝门控，不急于做大规模离散关系搜索。

可从下面的目标开始实验，其中 X 是代码点位，T 是图像对齐，μ/Σ 来自原图测量：

```text
测量误差：Σ_i robust((T x_i − μ_i)^T Σ_i^(-1) (T x_i − μ_i))
代码先验：λ0 ||X − X_generated||²
几何残差：Σ_j w_j r_j(X)²
保护条件：点顺序、已知关联、非退化、受影响边和曲线依赖
```

该式是采用成熟优化方法的研究起点，不应当作新求解器。新假设是：**根据测量可靠程度决定关系与移动，而非统一角度/位移阈值，可以在提高几何精度时降低误修复。**

实现落点：扩展 `GeometryObject.attributes` 或新增测量记录；为 `repair_tikz_constraints` 增加可选观测输入；在 `optimize_coordinates` 中加入测量权重和独立拒绝报告。保留当前 source-only 模式作为强消融。

必须比较：不修复、当前后修复配置、只做图像拟合、各向同性固定权重、测量加权但不筛选关系、完整方案。负例应包括真实 89.6°/90.4°、近但不平行、透视投影等；不能只有被人为扰乱的正例。

### B. 证据缺口驱动的局部重测：作为 A 的补充

**问题。** 代码遗漏可能源于没看到、没记录、没生成，三者处理动作不同；当前日志显示代码修复比重访感知更频繁，需用冻结checkpoint进行路由对照。

**方案。** 比较“原图证据—GES—生成代码—执行几何”四者的一致性。输出问题类型、对象、ROI、缺失证据、预计检查方式；根据它选择局部 CV 重测、Geometry 补充、代码局部修改或重新评审。重测后重新验证相关结构，再接受或回退。

现有 `scripts/test_repair_routing.py` 是可复用原型，但其说明已明确是小样本、额外调用、非等预算的重放实验，尚未形成正式主流程。部分默认归档路径还指向已移除的旧目录，需要改用新冻结归档或精确 checkpoint。

先修两项工程前置：CV 重跑目前会复用 `seg_01` 等局部编号，`add_object` 同 ID 会覆盖对象；引入 observation/run ID 与实体关联。随后建立代码对象与 GES 对象的显式绑定，避免仅凭同名推断对应。

先使用 3–4 个可审计路由和至多一次局部重测，不把“能动态调工具”当贡献。与相同模型预算的直接修复、固定全图重测、随机 ROI、仅加一次 Critic 对比。报告最终质量、修复成功率、无关对象退化、token 和延迟。

### C. 主体几何与注释分离的执行评测：必须做的验证，也可发展为次要贡献

当前已实现按可见标签绑定的固定角度/比例清单；下一步人工验证绑定语义，并将数学符号和文字排版作为单独诊断。不要把规则写成“忽略 A1/C1”：用生成的语义标记、路径归属、局部结构与执行结果共同判定，并用人工审核验证分类。

对于新方法可让 TikZ Agent 输出对象绑定表；外部 baseline 则用同一冻结提取器。不能只给自家方法提供正确类别。以编译后的坐标或路径核验为依据，兼容不同源码写法；未知语法明确记为不可测。

差异点需要超越 DiagramIR 的规则检查和 Diagram-MMU 的对象匹配：重点验证主体关系对应、辅助符号干扰、缺失条件和测量稳定性。若新协议与人工判断不一致，应先修协议，不用它证明方法更优。

### D. 构造依赖与曲线自由度：第二阶段备选

冻结圆上点能避免破坏曲线，也限制了纠错。数值圆上点可用单一角度 `p=c+r(cosθ,sinθ)` 表达；交点、垂足、切点通过构造依赖计算，使移动父对象时相关对象一致变化。

这能支持圆上点修复与后续编辑实验，但依赖恢复本身可能出错，不能仅凭图像认定一个点必定是中点或切点。GeoLoom 已有自由/依赖点，CAD 也广泛使用参数约束。因此它适合补足能力，4–6 周内不建议取代 A 作为主线。

### E. 测量价值驱动的工具预算：低成本辅助实验

给每个候选重测定义“可能影响的结构数量 × 当前证据不稳定程度 ÷ 调用成本”，只检查高价值 ROI；对 Supervisor 使用状态增量和按需证据，检查旧图是否在消息历史中持续传输。

当前 Supervisor 的 token 占比支持开展这个方向，但 token 多不证明压缩一定提高质量。需要质量—成本曲线，不单列 token 降幅。优先采用确定性排序作为基线，避免短期内再训练一个策略模型。

## 6. 最小而可信的论文实验包

### 数据与切分

- 将现有100图明确标为开发集，保留当前方法、对应消融、baseline及其冻结输入和执行日志。
- 建议另取约 300 张未使用图片做冻结测试；这是计划规模，当前本地并没有这些新增样本。先确认获取和标注条件。
- 按题目 ID 分组，保证同题 q/s、多张 figure、近重复图不跨开发/测试；合成数据按构图模板分组，不能仅换坐标就声称独立。
- 增加约 100–200 图的外部集合，优先选择有图元/关系标注的数据。PGDP5K/Geometry3K 可用于拓扑评估，不假设它们都有 TikZ 真值；使用作者许可和官方切分。
- 人工审计部分样本的参考与主体关系，独立于方法结果；记录分歧与仲裁，不能由同一生成模型自证正确。

### 两层实验，避免把额外采样当方法收益

**第一层：冻结源码的后处理。** 同一份 TikZ 对比所有修复方法，至少覆盖两个不同生成器的输出。当前已保留的外部 baseline 可以先做离线试验；结论要同时报告解析覆盖率。

**第二层：完整端到端。** 在冻结测试上比较现有系统与加入新机制的系统。路由对照共享首轮源码和精确 checkpoint，并匹配额外模型调用/预算。只有额外预算下更好，不能证明路由优于直接多生成。

最小组别：同模型直接生成；生成＋普通视觉 Critic 修复；现有 GeoAgent；现有后修复；仅图像拟合；选择性证据后修复；加局部重测。再加可获取的相关专用模型或 Geo-Code 可复现版本。复现不了时说明原因，不能用“受其启发的实现”冒充作者实现。

### 指标

| 类别 | 必报内容 |
|---|---|
| 主体几何 | MAE、MRE 的均值/中位数/p90，角度和比例的条目数、逐图分布 |
| 完整性 | 可解析率、主体边/点召回、拓扑 F1、匹配覆盖率；缺失项不能当零误差 |
| 约束 | 相对于独立真值的 precision/recall 和残差；不能只统计本方法自己选中的关系 |
| 修复风险 | 逐图改善/变差数量、主体结构破坏率、错误精确化率、拒绝率和接受后的误差 |
| 视觉 | 沿用 SSIM/CLIP/DINO 协议，补充局部主体线条距离；字体与标签单独评估 |
| 效率 | 模型调用、输入/输出/cache token、实际墙钟时间、重测次数、编译次数 |

采用固定真值条目表。条件 MAE/MRE 必须伴随覆盖率；可以另报“在全部真值条目中，既被正确恢复且误差小于阈值的比例”，避免删掉难边就得低误差。阈值在开发阶段固定，最好同时展示预先规定的多阈值曲线。

统计单位优先使用题目/图像，而非把同一图的数千条关系当独立样本；测试前冻结配置，报告配对区间。主比较提前确定，测试集不再做 反复择优。对新机制重复生成或多随机种子，以区分模型波动与修复收益。

下游解题是加分项，不是本轮必需。若开展，应比较原图、自动生成 TikZ、修复 TikZ 和参考 TikZ 的 oracle 上界，并固定题目、求解器与预算；当前本地仅图码数据尚不足以直接开展该实验。

## 7. 4–6 周执行安排与止损标准

以下为工作量估计，不是已安排的真实截止日期。

| 时间 | 交付 | 决策点 |
|---|---|---|
| 第 1 周 | 固定任务范围；审计参考/匹配；建立主体验证与负例；预留独立测试；完成对象观测 ID | 若主体真值无法可靠获得，先收窄到可信子任务，不继续用异常 MRE 选算法 |
| 第 2 周 | 原图对应、局部鲁棒测量、稳定性估计；接入当前后处理；与固定权重对照 | 若只降低自己选定关系的残差，却不降低真值误差或误修复，则不成立 |
| 第 3 周 | 完成选择性门控；一次局部重测；精确 checkpoint；冻结方法和主要比较 | 若局部路由的收益在等预算下消失，将其降为分析，不强行包装创新 |
| 第 4 周 | 独立测试和外部集合；消融；统计区间；统一生成器/渲染协议 | 若收益集中于极少数参考异常图或丢失覆盖率，应停止泛化主张 |
