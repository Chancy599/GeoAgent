# GeoAgent 流程与标签几何评测

## 生成和后修复

输入原图 → Supervisor调度CV → 几何证据状态GES（复杂构造可由Geometry Agent补测和归并） → Code Agent生成TikZ → 确定性坐标后修复 → 编译、渲染与拓扑检查 → Critic → 必要时再次测量或修改。

可靠的端点和折点证据直接生成必画边。有歧义的具名直线端点由Critic在渲染复查时对照原图确认。它可以选择已列出的候选或弃权，确认的连接会写入同一份必画边规格。程序随后重新检查TikZ是否用共享的具名端点画出这些边，并接受共线的具名分段。规格和各版本检查结果保存在`state.json`。

后修复读取生成代码，不读取参考源码。候选提取前识别由两条主体长边支持的小正交路径，排除其笔画及专用辅助点；支持命名、字面、简单偏移、相对坐标及拆成两条命令的符号。主体关系仍可作为候选，带标签的真实短几何受保护。近平行、近垂直和近共线关系来自生成的数值坐标与绘制线段；使用小位移、长度变化限制和曲线依赖冻结保护已有结构。默认直线关系容差0.5°、单点最大位移为图形对角线0.5%、已有边长最大变化1%，所有点对长度保护权重0.01，共线范围0.3%。曲线分支冻结曲线定义依赖及圆周、切线保护点，其余点仅修复近平行关系，共线范围0.2%。

参数见 `configs/default.json`。符号表达式、未支持的曲线和局部变换保留原样。导出回读或编译失败回退原始代码；内容与配置哈希防止重复写回。前置GES修复仍是显式可选实验设置，默认处理发生在TikZ生成之后。

## 参考清单：先提取，单独保存

运行`python scripts/build_geometry_reference.py --workers 20`，仅从`data/test/latex`提取，输出到`data/test/geometry_reference`。不访问生成结果，不根据预测筛选参考项。

`corrections.json`保存人工审核的参考构造修正，并用原始源码哈希防止误用。已审核修正6986的E：取BC与圆心O、半径OB的上半圆的第二交点，得到(-0.161002879, 2.995676563)。不修改原始TeX；原绑定保留在source_xy，所有依赖E的目标值在构建时重算。

每图JSON包含：

- 可见标签及其显式绑定坐标、内部坐标别名和绑定表达式。
- 实际绘制、两端均有标签的直线段。
- 具有公共带标签顶点的线段对所定义的角度和有序长度比。
- 参考数值、源码哈希、解析规则哈希，以及重复标签与绑定冲突。

标签坐标按代码表达式解析，包括内部别名、字面坐标、受支持的calc和交点表达式；picture/scope变换及数值x/y坐标基会作用于坐标。字号、above/left、anchor、文字xshift/yshift属于排版，不修改at绑定。

`\coordinate (P7) at (2,3); \node[above] at (P7) {$A$};`提取A=(2,3)，不要求内部坐标名为A。同名内部坐标与可见标签绑定不同时，记录冲突，使用可见标签的实际绑定。无标签点、辅助点、曲线上的无标签点和隐式交点均不创建评测顶点。

重复标签若精确绑定同一点则合并；绑定不同点则该标签无法解析，不选择最近点。没有可见标签的命名坐标也不参与评测。无明确绑定的路径位置标签暂报告不支持，不将其误绑定到路径端点。

## 测量项的确定规则

当前协议为`label-bound-v1`，只有一套活动实现。

1. 对所有带标签点对，保留非退化且被直线笔画支持至少95%的线段；有中间标签的组合线段也保留，例如AM、MB、AB。
2. 对有一个公共端点的线段对，角度大于等于5°时记录角度，范围为0–180°；所有非退化线段对记录长度比。
3. 线段端点及线段对均按标签排序，比例方向固定，不按预测翻转分子分母。
4. 小正交注释路径经过几何过滤；圆、圆弧、填充与非顶点文字不作为直线测量项。只含曲线的图可以没有角度与比例。

角度MAE为预测与参考角度差的绝对值，单位度。比例MRE为`abs(预测比例/参考比例 - 1)`，表格乘100显示百分比。二者越低越好。

源代码可能包含近似构造或不一致的标签，清单反映源码实际写出的绑定，不自动纠正数据，不从原图猜测其意图。字面文字坐标若被作者用作排版偏移，当前规则也不会擅自吸附到附近点；可通过绑定审计发现这类样本。明确审核过的参考错误通过独立corrections.json修正，不能根据某个预测结果选择修正值。

## 评测时只读清单

`scripts/evaluate_structure_ab.py`读取manifest中固定的100个图名和对应JSON，再从每个output档案读取同名生成代码。它不会打开参考TeX，也不运行Hungarian或空间对齐。预测中的标签直接对应参考同名标签。

对每条参考测量项，取预测中的同名点，检查所需线段是否非退化且实际绘制，再计算角度或比例。缺标签、重复冲突、缺边、退化边与程序无法解析都记录不可用原因，不替代为零误差。即便某组缺少整份程序，也保留该图及全部参考测量项的分母。

主表固定纳入全部 100 图、2371 个参考角度和 2915 个参考比例。缺测角度计 180°，缺测比例计 100%，可测比例误差封顶 100%。每张图先按参考项平均，再对 100 张图等权平均。线段覆盖率按图平均，角度和比例覆盖率按完整参考项计数。逐图记录保留原始误差和缺测原因。

## CV坐标的程序化传递

`geometry.preserve_cv_coordinates=true`默认开启坐标传递约束，独立于几何修复开关。程序按`label_bindings`取得当前CV测得的坐标，使用统一缩放、平移与y轴翻转计算TikZ坐标，统一保留三位小数后插入图形开头。原始CV测量与内部求解保留浮点精度；程序导出和后修复写回均采用三位小数，每轴舍入误差不超过0.0005个TikZ单位。Geometry Agent提交的同名舍入点不覆盖原始测量，也不再作为重复点传入TikZ提示。模型负责连接、样式和辅助构造，不再计算这些点的坐标。

第一版仅支持单个大写字母标签、来源为`cv:bind_point_labels`且绑定无歧义的有效点。Critic 可以从已有 CV 点中确认错绑或错读的标签，程序保留原始坐标并重验已有版本。生成前会自动测量线段和标签，渲染后会在样本充足时复核标签相对图形的大小。拒绝/冲突点和存在歧义识别的标签不固定；非支持标签、缺失CV测量仍走原生成流程。坐标契约不保证CV检测本身正确；若测量错误应重新测量或修正绑定，不能直接把测量理想化。受管理的标签必须引用同名坐标；重新定义、改变坐标系、scope和路径局部平移会被拒绝并要求重试。普通标签排版偏移允许保留。第一版不支持一般TikZ宏展开，也不保证模型生成的曲线半径及其他未测量参数正确。

坐标传递在确定性后修复之前完成。后修复仍有独立开关，求解器仍围绕其输入坐标做最小移动；已管理的点不再先经历模型的数值改写。后修复允许按现有限制改变这些坐标，这与生成时的数值传递属于不同阶段。每版的`tikz/vN/coordinate_contract.json`记录参与点、原始像素坐标、转换、排除原因；`unrepaired.tex`保存坐标写入后、约束修复前的代码。

通过`GEOAGENT_PRESERVE_CV_COORDINATES=0`可以单独关闭坐标传递约束；通过`--no-geometry-repair`可以单独关闭约束修复。后续效果对照应至少包含旧生成流程、CV直接导出、同一CV坐标经约束修复后三组，避免把弥补生成损失视为修复测量噪声的证据。


后修复先以浮点精度求解，再按三位小数导出，并重新检查实际导出坐标的位移、边长变化、点在线段上的顺序和方向残差。方向残差门限受配置角度容差与坐标量化产生的长度相关误差界共同限制；不把内部解的零残差当作导出结果。失败则保留统一量化后的不修复代码。可运行 `python scripts/verify_current_repair_exports.py` 核对本批已接受的后修复关系。

## 运行与产物

```powershell
python scripts/evaluate_structure_ab.py `
  --group haiku-5.5=outputs/baseline/haiku-5.5 `
  --group gpt-5.4=outputs/baseline/gpt-5.4 `
  --group qwen3.5-plus=outputs/baseline/qwen3.5-plus `
  --group glm-5.3-flash=outputs/baseline/glm-5.3-flash `
  --group ours=outputs/ours `
  --workers 20 --out results/latest/structure.json
python scripts/evaluate_visual_cached.py `
  --group haiku-5.5=outputs/baseline/haiku-5.5/image `
  --group gpt-5.4=outputs/baseline/gpt-5.4/image `
  --group qwen3.5-plus=outputs/baseline/qwen3.5-plus/image `
  --group glm-5.3-flash=outputs/baseline/glm-5.3-flash/image `
  --group ours=outputs/ours/image `
  --out results/latest/visual.json
python scripts/merge_evaluation_results.py
```

源码或解析规则更新后应重新构建清单。manifest保存参考JSON和原始TeX哈希；评测核验JSON与规则版本，评测过程不重新读取源TeX。如需确认源TeX更新，应运行构建步骤。

视觉评测使用相同100张图片、固定预处理和本地权重：SSIM为1000px白底画布上的灰度Gaussian SSIM，CLIP为ViT-L/14@224，DINO为DINOv2-base CLS。特征缓存按图片内容与编码配置哈希区分，缓存目录为`.cache/visual_evaluation`。

结果见[100图报告](../results/latest/report.md)。GeoAgent、Qwen3.5-Plus 和 GLM-5.3-Flash 均覆盖同一批 100 张图。

当前输出直接位于`outputs/ours/image`、`outputs/ours/latex`和`outputs/ours/stem`，评测记录集中于`results/latest`。四种方法的主表由本批逐项分数取共同项后汇总，覆盖率以完整参考清单为分母。

当前参考还修正6983的圆心O和圆周点E；1630按实际坐标、411保留原代码。符号不产生角度真值。CV端点恢复只处理未绑定标签，已有交点绑定不会与噪声端点重新竞争；浅折线和经核验的符号方向以源图测量为依据，不自动拉成对角线。
