# 带标签几何参考清单

每张图一个JSON。只包含从参考TikZ中直接提取的可见标签绑定、直线段、角度和线段比例，不包含生成结果。manifest固定图名、源码哈希和各JSON哈希。

构建：`python scripts/build_geometry_reference.py --workers 20`。

评测只读取本目录的清单并按同名标签测量预测，不读取参考TeX，不使用最近点匹配。规则详见[流程文档](../../../docs/pipeline.md)，当前结果见[100图报告](../../../results/latest/report.md)。
