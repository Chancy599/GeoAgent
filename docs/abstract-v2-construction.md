Geometric figures in textbooks and exams are often distributed as raster images. Recovering them as executable code makes them editable and reusable. Existing approaches, including end-to-end multimodal models, specialized models fine-tuned on large-scale data, and multi-agent systems with render-and-verify loops, primarily emphasize visual similarity. However, small angular deviations and distorted segment ratios can violate geometric relationships while remaining difficult to detect with image-based similarity metrics. High visual similarity alone therefore does not ensure geometric correctness. We argue that figure-to-code conversion should target not only visual similarity but also geometric fidelity. We present GeoConstruct, a system in which a Supervisor dynamically orchestrates sub-agents and tools over a persistent Geometric Evidence State. Computer-vision tools measure primitives and labels at the pixel level. A Geometry Agent integrates these measurements into geometric objects and relations, checks candidate parallelism, perpendicularity, and other geometric constraints against deterministic tolerances, and proposes small coordinate corrections. A Code Agent then generates parameterized TikZ code. After compilation and rendering, a Critic Agent locates discrepancies by comparing the original figure with the rendered output, closing the verification loop. On TriGeoBench, GeoConstruct outperforms the evaluated baselines in both visual similarity and geometric fidelity, with the latter measured by our constraint-level evaluation protocol covering angular error, segment-ratio error, and geometric-relation satisfaction.

教科书与试卷中的几何图形通常仅以栅格图像形式呈现。将其还原为可执行代码后，图形便可被编辑和复用。现有方法——包括端到端多模态模型、在大规模数据上微调的专用模型，以及带有“渲染—验证”循环的多智能体系统——主要关注视觉相似性。然而，微小的角度偏差和线段比例失真可能破坏几何关系，却难以被基于图像的相似性指标检测出来。因此，仅凭高视觉相似性并不能确保几何正确性。我们认为，图形到代码的转换不应只追求视觉相似性，还应追求几何保真度。为此，我们提出 GeoConstruct。该系统以持久化的几何证据状态为核心，由 Supervisor 动态编排各子智能体与工具协同工作。计算机视觉工具在像素层面测量图元与标签；Geometry Agent 将这些测量结果整合为几何对象与几何关系，依据确定性容差检查候选的平行、垂直及其他几何约束，并提出小幅坐标修正；随后由 Code Agent 生成参数化的 TikZ 代码。代码经编译与渲染后，Critic Agent 通过比对原始图形与渲染结果定位差异，从而闭合验证回路。在 TriGeoBench 上，GeoConstruct 在视觉相似性与几何保真度两方面均优于所评估的基线方法；其中几何保真度由我们提出的约束级评估协议衡量，涵盖角度误差、线段比例误差与几何关系满足情况。
