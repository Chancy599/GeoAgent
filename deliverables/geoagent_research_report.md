# GeoAgent 主流程接入与论文扩展实验

## 结论

论文主任务继续采用**原图到可编译 TikZ**。本轮接入的扩展混合后修复使 525 条已接受约束中的严格成立数从 **129 提高到 429**，并保持整批图的线段、角度和长度比覆盖率。编辑和查询实验可以作为下游用途，分别检验生成程序能否安全地改动，以及能否回答有明确数值判据的问题。

## 1. 主流程与 150 图复验

`GeoAgentRunner` 仍在 Code Agent 返回完整 TikZ 后启动后修复，再将选中结果交给编译、拓扑检查和 Critic。生成时的坐标契约仍使用三位小数。扩展混合以原求解器的浮点解为目标，在 TeX 的整数 `sp` 网格上寻找布局。编译后回读 PGF 点锚，垂直用整数点积为零验收，平行与共线用整数叉积为零验收。若无法同时满足所有关系，可以保留通过验收的子集或使用六位小数候选。原三位小数结果仍是失败回退，并可用 `--geometry-repair-mode legacy` 单独选择。[主流程后修复](../geoagent/state/repair_pipeline.py) · [坐标与证据说明](../docs/pipeline.md)

用归档的 150 份 Code Agent 输出、坐标契约和同批参考图重放主流程后修复。原三位小数分支逐图重放结果与归档一致。四个端到端基线沿用同批输出。这个设计隔离了后修复的影响，测试范围为固定生成输入下的后修复。

| 指标 | 原三位小数 | 主流程扩展混合 |
|---|---:|---:|
| 编译后严格成立 | 129 / 525 | **429 / 525** |
| 最大方向残差 | 0.133429° | **0.002951°** |
| 参考角度 MAE | 0.121035° | 0.121080° |
| 参考长度比 MRE | 0.398873% | 0.398896% |
| 线段 F1 | 99.7356% | 99.7356% |
| 对齐后点位误差 | 0.098919% | 0.099055% |
| SSIM ×100 | 94.2596 | **94.2768** |
| CLIP ×100 | **99.3543** | 99.3522 |
| DINO ×100 | 98.9568 | **98.9581** |

扩展混合严格满足 **229/260 条垂直、149/170 条平行、51/95 条共线**。配对重抽样以图为单位，10,000 次重抽样得到精确率增量 **57.14 个百分点**，95% 区间为 **46.88 至 67.23 个百分点**。参考角度 MAE 增量为约 **0.000045°**，95% 区间为 **−0.001014° 至 +0.001198°**。比例 MRE 的变化为约 **+0.000023 个百分点**，95% 区间为 **−0.001801 至 +0.001902 个百分点**。这些区间描述固定开发集上的配对差异。

三组消融的线段覆盖率分别为关闭修复 **99.6592%**、原三位小数 **100%** 和扩展混合 **100%**。两种后修复通过同样数量的归档拓扑计划，均为 140/150。89 张图进入扩展混合分支，编译读回中位数为 2 次。8 并发复验中该分支每张图的墙钟时间中位数为 10.60 秒，包含数值搜索和编译点锚回读。延迟取决于图形复杂度和编译负载。[五组主表](../results/extended_hybrid/report.md) · [三组消融与哈希](../results/extended_hybrid/ablation.md) · [逐图读回和耗时](../.cache/extended_hybrid/replay/replay.json)

## 2. 局部编辑

原型在输出 TikZ 的副本上执行三类显式命令。

- **换标签**保留点锚、字号、布局和几何路径，仅替换匹配节点内的数学标签。
- **加中点**只在有已绘制边支撑的位置新增点和标注，用 TikZ 的插值表达式定义中点。编译后检查中点满足 `2M = A + B`，容差为每轴 2 个 `sp`。中点靠近已有标签锚点时会拒绝。可以用 `--label-placement` 选择新增标签的位置。
- **切换实虚线**定位唯一的显式边或可确认的共线分段路径，保留其他边及标签。重叠、线型混合或复杂路径会被拒绝。

五种方法都用同一个工具。每张图根据参考清单和固定哈希选一条边，对每种方法发出同样的三条命令。源码阶段共 2,250 次尝试，验收时重新解析标签锚、直线和圆的集合。另用固定哈希预先抽取 30 张图，成功编辑的程序再编译并回读，按每个任务完整 30 次计分。预览输出包含 TikZ、PDF 和 PNG。[编辑原型](../scripts/edit_geometry.py) · [编辑与查询评测](../scripts/evaluate_geometry_reuse.py)

每个单元格依次给出全部 150 张的源码验收数，以及抽样 30 张的编译和回读验收数。

| 输入程序 | 换标签（源码 / 抽样） | 加中点（源码 / 抽样） | 切换实虚线（源码 / 抽样） |
|---|---:|---:|---:|
| haiku-5.5 | 150 / 30 | 134 / 22 | 84 / 20 |
| gpt-5.4 | 150 / 30 | 117 / 24 | 87 / 22 |
| qwen3.5-plus | 150 / 30 | 134 / 25 | 82 / 18 |
| glm-5.3-flash | 146 / 29 | 133 / 16 | 89 / 20 |
| GeoAgent | **150 / 30** | **140 / 28** | **131 / 27** |

GeoAgent 的源码验收为 **421/450**，抽样编译和回读验收为 **85/90**。其 131 次线型编辑中有 23 次修改了多段共线路径。原型只接受单段时，该任务通过 104/150。由此可见，比较不同方法的编辑结果时，既要看它生成了什么，也要看编辑器能处理哪些等价的路径写法。

未通过的 GeoAgent 任务包括 10 个中点过于靠近已有标签锚、17 条边无法定位唯一共线路径，以及 2 条边的分段混用了实虚线。编译抽样反映几何和代码条件。图面排版仍可用预览检查，新增标签位置可手动调整。例如在 `1479_q_fig4` 的 `BD` 上添加中点 `M`，标签放右侧。在 `1251_s_fig3` 中把由三段组成的 `AB` 改成虚线。[中点预览](../.cache/extended_hybrid/demo/midpoint_right.png) · [共线分段编辑预览](../.cache/extended_hybrid/demo/compound.png) · [逐任务结果](../.cache/extended_hybrid/reuse_final.json)

四组基线共有 17 次中点通过源码检查后未通过编译坐标检查。把每轴容差从 2 `sp` 放宽到 32 `sp`，其中 2 次会通过。偏差最大的样本使用了 `scale=0.02` 的图形坐标系，最大轴偏差为 58,925 `sp`。这些结果是当前编辑命令对各类生成程序的兼容性测量，可进一步比较局部坐标编辑和编译坐标编辑。[中点容差复核](../.cache/extended_hybrid/midpoint_tolerance_audit.json)

## 3. 从代码查询几何

从五组预测代码中提取同名标签、实际线段和点位，用数值规则判定角的类别，以及两条具名边哪条更长。角分类使用 1° 直角与平角窗口，排除紧邻分类边界的参考项。长度比较排除参考长边与短边之比小于 1.05 的项。每个可评测参考项都计入分母，缺点、缺边和不可测项计作未答对。此实验的输入是生成代码，题目和判分用冻结参考清单。

| 输入程序 | 四类角判定 | 其中直角 | 边长比较 |
|---|---:|---:|---:|
| haiku-5.5 | 3,853 / 4,542 | 564 / 616 | 4,258 / 5,094 |
| gpt-5.4 | 2,851 / 4,542 | 430 / 616 | 3,143 / 5,094 |
| qwen3.5-plus | 3,993 / 4,542 | 544 / 616 | 4,331 / 5,094 |
| glm-5.3-flash | 3,450 / 4,542 | 466 / 616 | 3,812 / 5,094 |
| GeoAgent | **4,528 / 4,542** | **609 / 616** | **5,094 / 5,094** |

GeoAgent 的角分类准确率为 **99.69%**。错分的 14 项均落在参考直角或平角类别。长度比较的满分对应相差至少 5% 的这一批题，等长判断仍需另设试验。

另外复核了归档拓扑计划中的 **42 个原图直角标记**，分布于 35 张图。编译读回后，16 个对应角严格垂直，5 个偏离 90° 超过 0.5°。`1251_s_fig3` 的 `∠ADB` 偏离约 2.15°，同一张图的 `BC ⟂ BO` 已经严格成立。经源图核验的角标和射线可以提供额外约束提议。[逐标记编译回读](../.cache/extended_hybrid/mark_audit.json)

在这 5 个偏差较大的例子上，把经核验的角标作为额外候选，与原来接受的约束一起重新求解。相同的位移和边长限制下，`1316_s_fig1` 和 `1494_q_fig1` 的浮点解达到 90°，原来接受的约束也得到保留。两例因边长变化超限而拒绝，余下一例受冻结点限制。这是浮点层的可行性试验，后续还需要验证导出与渲染效果。[额外角标候选试验](../.cache/extended_hybrid/mark_projection_trial.json)

## 4. 对论文的用法

1. **正文保留图形转代码。** 整图相似度、几何指标和覆盖率用于衡量重建。加一张编译后约束表，严格满足率的分母限定为系统接受的关系。参考角度 MAE 涵盖完整参考清单。当前开发集仍需留出独立测试集复验。
2. **把编辑放在应用与补充实验。** 用同一组局部任务和相同编辑器比较各方法的产物，评测目标实现和无关图元保留。Edit2TikZ 已把科学图表编辑作为独立问题，本项目可聚焦几何专属的点线构造、约束验证和不确定时拒绝编辑。自然语言到编辑命令、曲线编辑和多步编辑仍需单独评测。[Edit2TikZ](https://arxiv.org/abs/2608.13441)
3. **把可执行查询作为几何语义检查。** 当前实验能检查读出的角和边长关系。后续可用带来源的构造图导出中点、垂足或圆切线的依赖，评测移动一个点后仍有多少约束成立。GeoBuildBench 可为可执行构造及判分提供参照，Penrose 可为声明式约束和可变布局提供参照。[GeoBuildBench](https://arxiv.org/abs/2605.13167) · [Penrose](https://penrose.cs.cmu.edu/siggraph20)

重建和这两项下游实验均使用同一开发集。查询得分来自代码测量，编辑得分包含语法可寻址性。两项结果都不宜外推成新图上的证明能力、通用自然语言编辑成功率或任意 TikZ 的可编辑率。
